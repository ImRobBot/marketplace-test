# Marketplace con TypeScript

Aplicación de ejemplo completamente migrada a TypeScript, con backend Express y frontend React + Vite.

Carpetas:
- `backend` - API Express escrita en TypeScript y compilada a `dist`
- `frontend` - SPA React escrita en TypeScript y compilada con Vite

Cada carpeta incluye sus propios comandos de desarrollo, pruebas, comprobación de tipos y compilación.
