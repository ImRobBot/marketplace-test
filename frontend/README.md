# Frontend (React + TypeScript + Vite)

Instrucciones rápidas:

1. Entrar a la carpeta `frontend`.
2. Ejecutar `pnpm install --frozen-lockfile`.
3. Ejecutar `pnpm run dev`.

Para comprobar los tipos sin generar archivos, ejecuta `pnpm run typecheck`.

La app intenta consumir la API en `http://localhost:4000`.
